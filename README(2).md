# Fake News Detection using GRU

## Project Structure

    Fake-News-Detection/
    │── app.py
    │── fake_news_gru_model.keras
    │── tokenizer.pkl
    │── requirements.txt
    │── README.md

## Install

``` bash
pip install -r requirements.txt
```

## Run

``` bash
streamlit run app.py
```

## Model

-   GRU Neural Network
-   Binary Classification
-   Labels:
    -   0 = Fake News
    -   1 = Real News
